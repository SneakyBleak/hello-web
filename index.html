My terminal cheat sheet

code - opens VS Code

ls - lists the files

pwd - shows the path address

cd - walks into the folder

cd .. - goes back one folder

mkdir - makes a new folder

touch - creates an empty file

cp - copies the file

mv - moves the file

rm - removes the file
